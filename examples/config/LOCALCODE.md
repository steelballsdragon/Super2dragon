# Project notes for LocalCode

## Commands
- Install: `npm ci` (ask before running; it needs network access)
- Tests: `npm test` (fast, run after every change)
- Type check: `npx tsc --noEmit`
- Lint: `npm run lint`

## Conventions
- TypeScript strict mode; no `any` in new code.
- Keep functions small; prefer pure functions in `src/lib/`.
- Every bug fix gets a regression test in `test/`.

## Do not touch
- `src/generated/` (generated by `npm run codegen`)
- `migrations/` that are already released
